# MyNotes

MyNotes is a personal fork of **Meetily** (https://github.com/Zackriya-Solutions/meetily),
based on release v0.4.1, Copyright (c) 2024 Zackriya Solutions, licensed under the MIT License
(see `LICENSE.md`, which is preserved unchanged).

Changes in this fork:
- Notes panel during recording; notes are attached to the meeting and merged with the transcript for summaries
- Default "MyNotes" summary template (Summary, Decisions, Action Items, Open Questions); prompt rules forbid invented owners/deadlines
- Markdown export (summary + notes + transcript) to the Downloads folder
- Meeting search also matches your own notes
- Branding (product name, window title, app identifier)
- Upstream telemetry (PostHog) and upstream auto-updates disabled
